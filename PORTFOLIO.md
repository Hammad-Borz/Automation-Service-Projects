## Portfolio capabilities

- Python business automation
- REST API integration
- Web data extraction and processing
- AI-assisted document workflows
- AI assistants and tool calling
- Retrieval-Augmented Generation (RAG)
- Email automation
- Excel and business reporting
- SQLite and SQL analytics
- Validation, testing, logging, and modular architecture

## Running a project

Each project is self-contained. Open the relevant project folder, install its requirements, and follow its README instructions.

Typical commands are:

```powershell
python -m pip install -r requirements.txt
python -m pytest -q
python -m src.main
```

## Engineering approach

The projects emphasize a repeatable pattern:

```text
Business Problem → Modular Design → Validation → Automation → Testing → Documentation
```

For detailed architecture, features, and usage, open the README inside each project directory.
